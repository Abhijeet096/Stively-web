# Brand Principles

Different from the Canva brand kit (`D:\Stively\Stively Brand kit\`) — that's how Stively *looks*. This is how Stively *behaves*. It's what should shape every email, proposal, support reply, and UI copy decision, so the voice stays consistent regardless of who's writing it.

1. **Professional, not corporate.** Confident and direct, never stiff. The marketing site's own copy is the reference: plain verbs, no filler, no "leverage synergies" — see how `/website-development`'s FAQ or `/process`'s copy actually reads.

2. **Transparent pricing, always.** No "contact us for pricing" hiding real numbers. `/pricing` and `/website-development` already show real starting prices and real package breakdowns — every future pricing surface should hold that same line, including custom quotes: scope and price get written down and approved before work starts, never negotiated verbally after the fact.

3. **Fast communication.** The 15-minute call target in SOP.md's Sales section is this principle in practice. A client should never have to wonder if their message landed.

4. **AI assists; humans remain accountable.** The interview scoring system is the concrete example of this already built and shipped: integrity-violation counts are shown to a recruiter as a signal, never used to auto-reject a candidate — a human always makes the actual call. Every future AI feature should follow that same shape: AI surfaces information and drafts, a person decides.

5. **Long-term partnerships over one-off projects.** Post-launch support isn't an upsell bolted onto the end of a project — it's already framed that way in the existing FAQ copy ("software needs upkeep, not a one-time handoff"). Warranty windows, maintenance plans, and ongoing communication all exist because the relationship doesn't end at deployment.

6. **No fabricated proof.** No invented stats, no placeholder client logos, no testimonials before real ones exist. This is already a hard rule for the marketing site (AGENTS.md) — it's a brand principle, not just a copywriting rule, and it applies everywhere: proposals, sales calls, case studies.

7. **Say what you don't know.** If a lighter, cheaper solution genuinely fits a prospect better than what Stively sells, say so — this is already live copy on `/website-development` ("We'll say when you don't need us"). Trust compounds; a single oversold project doesn't.
